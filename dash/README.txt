Konkan Social Media & Crisis Impact Dashboard
Open index.html in any browser (works completely offline; Chart.js is bundled in vendor/).

Optimized for:
- Desktop & large screens (comprehensive table view, wide analytics grid)
- Smartphones & touch devices (smooth swipeable district pills, 2x2 compact KPI grid, touch event cards, quick search & category filters, floating chart jump button)

Files:
- index.html: Main semantic dashboard markup with responsive meta viewport
- styles.css: Modern responsive styling with touch ergonomics & modern color palette
- app.js: Interactive filtering (district, type, search, event), dynamic Chart.js rendering
- data.js: Event master list (EVENTS) and modelled transmission metrics (metrics)
- vendor/chart.umd.js: Offline bundled Chart.js
